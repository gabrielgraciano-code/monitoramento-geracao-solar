# ☀️ Sistema Automatizado de Monitoramento de Geração Solar

Ferramenta desenvolvida para o acompanhamento diário e automatizado de plantas solares fotovoltaicas, integrando dados de inversores e plataformas de monitoramento para análise de performance.

## 📌 Funcionalidades
- **Coleta de Telemetria:** Extração diária de dados de geração de energia fotovoltaica integrada via plataforma SolarZ e inversores.
- **Análise de Desempenho:** Cálculo automático da produção diária em comparação com as estimativas e médias regionais esperadas.
- **Geração de Relatórios:** Criação automatizada de resumos diários de performance para auditoria e acompanhamento operacional de Geração Distribuída (GD).

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Integração de APIs/Plataformas:** SolarZ / APIs de Inversores Fotovoltaicos
- **Manipulação e Análise de Dados:** Pandas / `openpyxl`
- **Automação de Rotinas:** Scripts agendados para acompanhamento diário

## 🎯 Objetivo do Projeto
Otimizar o acompanhamento técnico de usinas solares, identificando rapidamente desvios de geração, perdas de eficiência ou falhas em dataloggers, garantindo maior previsibilidade para o setor de Geração Distribuída.
